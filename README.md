## 🚀 কীভাবে চালাবেন ও দেখবেন (How to Run)

### পদ্ধতি ১: যেকোনো ব্রাউজারে সরাসরি ওপেন করুন
আপনার ফোনের ফাইল ম্যানেজার থেকে বা ব্রাউজারে নিচের ফাইলটিতে ট্যাপ করলেই সাইটটি সরাসরি দেখতে পাবেন:
`file:///storage/emulated/0/Antigravity/lucceass-topup/index.html`

### পদ্ধতি ২: লোকাল সার্ভারে রান করা (Termux থেকে)
টার্মিনালে রান করতে পারেন:
```bash
python3 -m http.server 8080 --directory /storage/emulated/0/Antigravity/lucceass-topup
```
এরপর ব্রাউজারে `http://localhost:8080` ভিজিট করুন।
